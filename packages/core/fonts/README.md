# fonts/

`ClaimseedNotdef-Regular.ttf` is a two-glyph TrueType font (`.notdef` box and space) generated by
fontTools and dedicated to the public domain (CC0 1.0). It is the only font visible to the renderer's
fontconfig (see `src/browser.js`), so text is drawn exclusively from the bundled @fontsource web fonts
(inlined as data: URIs by `templates/partials/fonts.html`), and any character those faces lack renders
as a visible box instead of being pulled from a machine-dependent system font. This keeps PDF bytes
identical for a given Chrome build on Linux (where fontconfig applies); `test/render-output.test.js` fails if any font other than the bundled faces and the PDF-standard Helvetica used for the stamped markers appears in output, and `test/font-coverage.test.js` (with `fonts/coverage.json`, regenerated by `scripts/font-coverage.py`) fails if any character in templates, stock content, scenarios or generator strings lacks a glyph in the bundled faces, because a missing glyph renders as that face's own box, which pdffonts cannot see.
